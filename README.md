# ООО «СЕРВИС»

Публичная статическая сборка информационного сайта компании.

Прачечное обслуживание, экипировка пассажирских поездов, клининг, складские и вспомогательные производственные работы.

Сайт подготовлен на Vite, TypeScript и CSS. Репозиторий содержит готовые файлы для GitHub Pages; дополнительная сборка на хостинге не требуется.

Шрифты Oswald и PT Sans используются по SIL Open Font License 1.1. Полные лицензии находятся в папке licenses.
